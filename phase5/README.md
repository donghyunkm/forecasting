# Phase 5 — Vital Sign Forecasting with Waveform Correlation Features

Forecasts 4 vital signs (ABPMean, PULSE, SpO2, RESP) 2 hours into the future using 6 hours of history, enhanced with 7 waveform-derived correlation features that capture cardiovascular coupling dynamics.

## What's New (vs Phase 4.2)
- **+7 correlation features** from mimicEran waveform analysis as additional input
- **5-min resolution** (vs 15-min) — finer temporal dynamics
- **6h→2h forecast** (vs 18.75h→6.25h) — shorter but more clinically actionable

## Quick Start

```bash
# 1. Prepare data (CPU job, ~10 min)
cd tft && sbatch prepare_data.sh

# 2. Train TFT (GPU job)
cd tft && sbatch train.sh

# 3. Train iTransformer (GPU job)
cd iTransformer && sbatch train.sh
```

## Data

**Source:** `/gpfs/home/dk5565/mimicEran/output/merged/`

11-dim feature vectors at 5-min stride:
- [0–6] Pearson correlations between waveform feature pairs (20-min window)
- [7–10] Vital signs: ABPMean, PULSE, SpO2, RESP (median over 20-min window)

**Processing:** Group by patient/segment → sort by time → sliding windows (96 steps = 72 input + 24 output) → discard windows with any NaN → normalize → save tensors

**Current dataset** (42/50 extraction parts): Train 10,917 / Val 2,318 / Test 2,191 windows

## Results

### Overall (median quantile)

| Model | MAE | RMSE |
|-------|-----|------|
| iTransformer | **3.18** | **5.37** |
| TFT | 3.28 | 5.48 |

### iTransformer Per-Vital

| Vital | MAE | Correlation | Calibration |
|-------|-----|-------------|-------------|
| ABPMean | 5.68 mmHg | 0.850 | 77.9% |
| PULSE | 4.11 bpm | 0.930 | 79.7% |
| SpO2 | 0.89% | 0.795 | 78.7% |
| RESP | 2.05 br/min | 0.812 | 78.0% |

### vs Phase 4.2 (vitals-only input)

| Metric | Phase 4.2 | Phase 5 | Δ |
|--------|-----------|---------|---|
| Overall MAE | 4.09 | **3.18** | -22% |
| Correlation (mean) | 0.780 | **0.847** | +8.5% |
| Calibration (mean) | 76.4% | **78.6%** | +2.2pp |

Correlation features from waveform analysis provide +6–13% correlation improvement across all vitals. Both models benefit equally.

**⚠️ Caveat:** This comparison is NOT apples-to-apples — Phase 5 uses a shorter forecast horizon (2h vs 6.25h) and finer resolution (5-min vs 15-min). Improvements are partially expected from the easier forecasting task. A controlled ablation (same data/horizon, with vs without correlation features) is needed to isolate the true contribution of waveform features.

## Architecture

**Single model** predicts all 4 vital signs simultaneously (not one model per vital).

| | TFT | iTransformer |
|---|-----|--------------|
| Input | (72, 12) = 11 features + time | (72, 12) = 11 features + time |
| Output | (24, 4, 3) = 4 vitals × 3 quantiles | (24, 4, 3) |
| Key params | state=240, LSTM×2, heads=2 | d_model=256, layers=3, heads=4 |
| LR | 1e-3 | 1e-4 |
| Loss | Quantile (pinball) | Quantile (pinball) |
